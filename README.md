*   **Fundamentals & Operations:** Linux CLI, Git, Shell Scripting, secure networking concepts.
*   **Secure Backend Development:** Building robust APIs with **Python** & **FastAPI**, input validation (Pydantic), and database security (PostgreSQL).
*   **Web Application Security:** Deep dive into the **OWASP Top 10** using the **PortSwigger Web Security Academy** (business logic flaws, JWT, API security).
*   **Infrastructure & Container Hardening:** Containerized deployments via **Docker**, host hardening (SSH, UFW, fail2ban), and Infrastructure-as-Code (IaC) with **Terraform**.

*   **Cloud Security & Identity:** Microsoft Azure fundamentals, identity management (IAM) and role-based access control (RBAC) via Microsoft Entra ID.
*   **Emerging Tech (AI Security):** Hardening AI interfaces and securing LLM applications (OWASP Top 10 for LLMs, Prompt Injection, Secure AI Gateway).
